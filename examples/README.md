# examples/ — 最小可用样本

本目录给一个**虚构的 Skill 项目**（面部瑜伽直播复盘 Skill）做演示，让你看清三件事：

1. 用户原话.md 真实长什么样（编号 + 引号 + 不改写）
2. 业务事实.md 四个区怎么分（用户事实 / 源文件 / AI 推断 / 已被修正）
3. 决策日志.md 三段式怎么写（决定 / 原因 / 影响）
4. 问题池.md 三个优先级怎么分（🔴 / 🟡 / 🟢 / ✅）

样本刻意做短（每个文件 30–50 行），看完应该 2 分钟就懂结构。

## 目录结构

```
examples/
  README.md           ← 你正在读的这个
  memory-sample/      ← 主记忆区样本（用业务 Skill 的视角）
    用户原话.md
    业务事实.md
    决策日志.md
    问题池.md
```

## 怎么用

把 `memory-sample/` 当模板复制到你自己的项目旁边，改名（如 `claude-notes/` 或 `memory/`），然后开始追加。

> 提示：示例里所有内容都是虚构的，仅用于演示文件结构和写法规则，不代表任何真实 Skill 的设计结论。
