### D001 - 不新建 Skill，做现有 Skill 的「面瑜变体」

决定：
- 不从零写一个面瑜专用 Skill，而是在 content-persona-streamer-review 基础上加一个 archetype 子模块 `facial-yoga`。

原因：
- 现有 Skill 的「知识情感型 + 带货型」叠加范式已经覆盖了 U004 的两阶段需求。
- 复用 Manifest 和九维评估骨架，避免规则漂移。
- 用户 [U005] 只反对 HTML 输出，没有反对评估框架本身。

影响：
- 新增 archetypes/facial-yoga.md，描述穴位识别、教学段评估侧重、带货段迁移性判断。
- 输出层加一个 SVG 渲染模板（替代 HTML），不动评估逻辑。
- UPDATE_LOG.md 第一条记录此决策。

### D002 - 话术迁移性分三级，不用二级

决定：
- 话术迁移性标记从 U003 的「✅/⚠️」二级，扩展为「✅ 通用 / 🟡 同品类可迁移 / ⚠️ 强人设绑定」三级。

原因：
- 真实样本中存在「面瑜专用但跨达人可用」的中间态（例如某些穴位话术），二级不够。
- 与用户在 U003 中确认过——同事看完同意分三级。

影响：
- 话术拆解表新增「迁移性」列，三种标签。
- 短视频切片脚本沉淀时，只挑 ✅ 和 🟡，不挑 ⚠️。
- 待真实样本验证（见 TODO.md 中「等真实样本验证」分区）。
