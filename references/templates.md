# 留存文档模板

---

## 用户原话.md

```markdown
# 用户原话记录

本文件保存用户关于本 Skill 项目的原始描述和想法。

原则：
- 尽量保留原话，不改写，不总结。
- 不混入 AI 判断或推断。
- 一条关键信息一个编号，追加不覆盖。

## YYYY-MM-DD

### U001 - 标题

> 原话
```

## 协作说明.md

```markdown
# 协作说明

## 角色分工

- 主记忆区维护者：主导 Skill 设计、执行落地、产品形态草图、决策日志。
- 审查区维护者：独立审查，质疑假设，识别盲区，补充替代方案，不从属于主记忆区。

## 文件所有权

- 每个 agent 只写自己文件夹内的文件，不覆盖对方文件。
- 用户原话只有一份，写在主记忆区的用户原话.md，两个 agent 均可引用。

## 分歧处理

- 分歧必须明确记录，各自写在自己的文件里。
- 由用户拍板，不得私下消除分歧。
- 分歧本身是有价值的，不是噪音。

## 信息同步

- 用户补充新信息后，两个 agent 各自独立更新自己的文件。
```

## UPDATE_LOG.md（放在业务 Skill 文件夹内）

```markdown
# [skill-name] 更新迭代记录

## 迭代原则

- 这个 Skill 会通过真实样本逐步变准。
- 每次重大修改都记录来源、问题、修改、影响、待验证点。
- 没有真实样本检验过的规则，标注「假设待验证」。

## YYYY-MM-DD · v0.1.0 · 第一版创建

来源：
- ...

初始假设（待验证）：
- ...

待验证：
- 用什么样本验证第一版规则是否成立
```
